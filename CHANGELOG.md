## 0.1.0 (2026-08-21)

### Features

* Phase 0: bun-workspace monorepo with a single Cloudflare Worker (Hono API + Vite/React SPA), Biome/TypeScript tooling, Vitest projects running in `workerd` against real D1/KV/Queue/Email bindings, CI workflow, config-guard tests
